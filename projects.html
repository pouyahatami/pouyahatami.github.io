Simple RISC Machine

Nov 2024 · Verilog · DE1-SoC FPGA · ModelSim, Quartus

A 16-bit RISC processor designed and implemented in Verilog, then deployed on an FPGA.

  • Built a datapath architecture — registers, ALU, and multiplexers — to perform arithmetic operations such as addition and subtraction
  • Designed a finite state machine (FSM) for instruction execution, automating control signals and managing state transitions
  • Wrote testbenches for each module to verify functional correctness through simulation

Reflow Oven Controller

Feb 2024 · EFM8 microcontroller

Designed and built a reflow oven controller to automate PCB soldering.

  • Implemented temperature measurement using a K-type thermocouple with cold junction compensation, achieving ±3°C accuracy
  • Developed a PWM control system to regulate a 1500W toaster oven via a solid-state relay (SSR)
  • Designed a pushbutton + LCD interface to select reflow profiles and display temperature, time, and process state
  • Enabled temperature monitoring by streaming data over a serial connection to a PC for strip-chart plotting

Interrupt-Driven Real-Time Alarm Clock

Jan 2024 · N76E003 microcontroller · Assembly

An alarm clock system programmed in assembly language on the N76E003 microcontroller.

  • Implemented timer interrupts to handle multiple concurrent tasks — timekeeping, user input, and alarm triggering
  • Displayed time in 12-hour format (AM/PM) on an LCD, with real-time clock adjustment via pushbuttons
  • Designed an interrupt service routine (ISR) generating a 2kHz square wave for the alarm sound through a mini speaker

FSM Lock

Verilog · DE1-SoC FPGA · ModelSim, Quartus

A digital combination lock implemented as a finite state machine in Verilog.

  • Simulated and synthesized the design with ModelSim and Quartus
  • Built user interaction through pushbuttons and seven-segment displays
