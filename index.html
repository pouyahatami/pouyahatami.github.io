RV32I Pipelined Processor Core

SystemVerilog · Five-stage pipeline · Spike-referenced verification

A five-stage RV32I processor with forwarding, hazard handling, M-mode CSRs, exceptions, timer interrupts, memory-mapped UART, and external halt/resume debug. Directed regressions compare architectural results against the Spike reference model under both Icarus and Verilator.

SIMT Matrix Multiply Accel

SystemVerilog · DE1-SoC FPGA (Cyclone V)

A fixed-function SIMT accelerator built from scratch — no vendor IP — and the first milestone toward a full SIMT GPU. Four cores share arbitrated memory ports, with contention instrumented rather than hidden.

RISC-V Run-Control Debugging

Undergraduate research · Prof. Guy Lemieux, UBC ECE

Reverse-engineered execution-based debugging in a RISC-V soft core and published an open-source tutorial on the GDB–OpenOCD–Debug Module workflow — work a co-author of Digital Design and Computer Architecture flagged as a potential reference for an upcoming textbook chapter.

Team project · UBC ELEC 391, Group 9

A rack-and-pinion carriage positions a bank of six solenoid-driven fingers along a keyboard, playing songs parsed from MIDI files. Led firmware: motor control, solenoid timing, and the serial link to the Python GUI.
